## Tech Stack & Architecture

### Frontend Technologies:
- **Markup:** HTML5 (Semantic elements, Open Graph tags, JSON-LD Schema.org structured data)
- **Styling:**
  - Custom CSS3 (Modern CSS variables, flexbox, grid, glassmorphism, depth overlays)
  - **Bootstrap 5 (v5.3.3):** Responsive grid, navbar, offcanvas, accordion, modals
  - Responsive layout media queries (`css/responsive.css`)
- **Typography & Icons:**
  - **Fonts:** Syne, Plus Jakarta Sans, Geom font family
  - **Icons:** Iconify (`iconify-icon`) via CDN (Material Design Icons `@mdi`)
- **JavaScript & Interactive Libraries:**
  - Native Vanilla JavaScript (DOM manipulation, counters, smooth scrolling, active navigation)
  - **AOS (Animate On Scroll v2.3.4):** Scroll-triggered entrance animations
  - **Swiper.js (v11):** Touch-enabled carousels and sliders
  - **Custom Scripts:**
    - `js/critical.js` (Preloader, viewport checks)
    - `js/script.js` (Main theme interactions, mobile nav, counters)
    - `js/whatsapp-forms.js` (Direct form submission via WhatsApp API)
    - `js/career.js` & `js/service-page.js`
- **Media Formats:**
  - WebP images (`.webp`) for lightweight, high-performance loading
  - MP4 video (`Orb.mp4`) background loops
  - PNG favicon
- **SEO & Structured Data:**
  - Schema.org `LocalBusiness` JSON-LD configuration
  - Open Graph meta tags for social sharing
  - Canonical link tags
